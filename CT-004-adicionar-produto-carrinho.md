# CT-004 – Adicionar produto ao carrinho

## Objetivo
Verificar se o sistema permite adicionar um produto ao carrinho de compras.

## Pré-condição
Estar logado no SauceDemo com o usuário standard_user.

## Passos
1. Acessar https://www.saucedemo.com/
2. Realizar login com credenciais válidas.
3. Localizar o produto Sauce Labs Backpack.
4. Clicar em Add to cart.
5. Verificar se o ícone do carrinho mostra a quantidade 1.
6. Acessar o carrinho de compras.

## Resultado esperado
O produto deve aparecer no carrinho com quantidade 1.

## Resultado obtido
O produto foi adicionado corretamente ao carrinho, apresentando a quantidade esperada.

## Status
PASS — Aprovado.
