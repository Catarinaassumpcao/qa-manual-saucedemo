# CT-002 – Login com senha inválida

## Objetivo
Verificar se o sistema impede o acesso quando o usuário informa uma senha incorreta.

## Pré-condição
Estar na página de login do SauceDemo.

## Passos
1. Acessar https://www.saucedemo.com/
2. Informar o usuário `standard_user`.
3. Informar uma senha incorreta: `senha123`.
4. Clicar em Login.

## Resultado esperado
O sistema deve impedir o login e apresentar uma mensagem informando que o usuário ou a senha estão incorretos.

## Resultado obtido
A registrar após executar o teste.

Pendente de execução.
