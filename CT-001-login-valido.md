# CT-001 — Login com credenciais válidas

## Objetivo
Verificar se o usuário consegue acessar o sistema SauceDemo utilizando credenciais válidas.

## Pré-condição
Estar na página de login do SauceDemo.

## Passos
1. Acessar https://www.saucedemo.com/
2. Informar o usuário `standard_user`.
3. Informar a senha `secret_sauce`.
4. Clicar em Login.

## Resultado esperado
O sistema deve permitir o acesso e apresentar a página de produtos.

## Resultado obtido
A registrar após executar o teste.
